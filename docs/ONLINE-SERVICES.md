# Онлайн-сервисы в Pixel Player 1.5

Pixel Player не связан с Яндексом, SoundCloud или Spotify. Онлайн-функции необязательны.

## Spotify

Используется официальный Web API и Spotify Connect. Настройка, данные и отзыв доступа описаны в [Spotify](SPOTIFY-PRIVACY.md). Плеер проверяет подтверждение запуска трека, а не только успешный HTTP-ответ. Отказ или отсутствие подтверждения показываются в интерфейсе; серверные ограничения Spotify не обходятся.

## Яндекс Музыка и SoundCloud

Внутри приложения открываются отдельные окна официальных сайтов `music.yandex.ru` и `soundcloud.com`. Это браузерный режим подключения: пользователь входит через сайт сервиса и использует его собственную коллекцию, поиск, очередь и воспроизведение. Автоматического импорта коллекций через API в локальную библиотеку нет.

Пароль вводится только на странице самого сервиса. Pixel Player не читает содержимое страниц, пароли или токены, не извлекает аудиопотоки и не загружает файлы музыки. Браузерные куки и кэш хранятся в отдельных постоянных профилях `pixelplayer-online-yandex` и `pixelplayer-online-soundcloud` внутри данных Chromium в папке `PixelPlayer-data` рядом с портативным EXE. Для выхода в этом плеере откройте «Онлайн» → нужный сервис → «О подключении» → «Выйти в этом плеере» и подтвердите очистку локальных данных. Это не удаляет аккаунт или музыку у провайдера. Закладки сохраняются отдельно и остаются после выхода.

Страницы сервисов изолированы от основного интерфейса: sandbox включён, Node.js выключен, preload-моста нет. Загрузка файлов, доступ к камере, микрофону, местоположению и другим запрашиваемым разрешениям в этих окнах не предоставляются. Навигация верхнего уровня ограничена HTTPS-доменами сервиса и известными страницами входа. Если сторонний вход или защита контента требуют возможностей обычного браузера, используйте «Открыть в браузере».

При открытии онлайн-сервиса локальная музыка ставится на паузу. Внешний сервис управляет своей музыкой самостоятельно; чтобы остановить её, используйте его кнопку паузы либо закройте окно. Закрытие главного окна Pixel Player (кроме сворачивания в трей) закрывает также окна сервисов. Выход из Pixel Player закрывает все такие окна.

## Закладки

Хранятся только выбранный сервис, название, публичный адрес и тип ссылки в `data/online-bookmarks.json`. Метки отслеживания и фрагменты URL удаляются. Закладки не отправляются ИИ-агенту и не публикуются разработчиком. При открытии ссылки сайт сервиса получает обычный браузерный запрос. На текущем этапе имена задаются пользователем; обложки и названия не извлекаются из закрытых аккаунтов.

## Ограничения

Подписки, региональная доступность, реклама, разрешения правообладателей и поддержка браузера определяются сервисами. Успешная загрузка окна не гарантирует полное воспроизведение или вход. Эквалайзер, скорость, кроссфейд и синхронизированные тексты Pixel Player применяются к локальным файлам.

У SoundCloud официальный API существует, но получение собственных ключей разработчика требует [Artist Pro](https://developers.soundcloud.com/docs/api/register-app). Версия 1.5 использует сайт SoundCloud и не включает чужие API-ключи. Яндекс Музыка также открывается через официальный сайт; недокументированные способы получения токенов не используются.
