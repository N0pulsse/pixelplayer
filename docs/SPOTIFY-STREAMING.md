# Spotify в Pixel Player 2.0

Стартовый экран приложения — Spotify. Локальные файлы находятся в разделе «Локальные», остальные сервисы — в разделе «Сервисы».

## Два режима

- **В Pixel Player** использует официальный Web Playback SDK. Звук остаётся внутри приложения. Требуются Premium, повторный вход с разрешением `streaming` и сборка с производственной подписью Widevine/VMP.
- **Spotify Connect** управляет официальным Spotify на другом устройстве. Встроенный режим не переключается на него автоматически и не запускает отдельный Spotify при ошибке.

Для первого запуска встроенного режима откройте настройки Spotify, войдите заново, подтвердите доступ на сайте Spotify, затем нажмите «Включить в Pixel Player». Первое подключение может занять время: защищённый движок устанавливает Widevine из своего штатного источника. Музыка не скачивается в локальную библиотеку.

При ошибке воспроизведения встроенный сеанс немедленно отключается: это останавливает звук и предотвращает автоматический переход по неудачным трекам. Кнопка «Стоп» доступна даже без повторного подключения. Нажатие на песню само подключает встроенный движок.

Пауза, продолжение, переходы и перемотка встроенного режима идут непосредственно в SDK. Spotify Connect перед командой определяет актуальное устройство и проверяет подтверждение паузы. Нижняя панель принимает нажатия мышью и содержит перемешивание, предыдущий/следующий трек, повтор, громкость и волнистую шкалу. На узких окнах громкость скрывается, остальные основные кнопки доступны.

## Защита входа

SDK работает на отдельном origin `pp://stream`, в изолированном iframe без Node.js, Electron preload и доступа к родительскому интерфейсу. Краткоживущий access token передаётся только этому iframe после проверки origin и окна-источника. Refresh token остаётся зашифрованным в профиле приложения. SDK не получает пути локальных файлов или ключи ИИ.

## Сборка с Widevine

Используется официальный Castlabs Electron for Content Security. Для производственного стриминга требуется бесплатная регистрация EVS и подпись собранного приложения. Установите `castlabs-evs`, авторизуйте свой аккаунт вне репозитория и перед сборкой задайте `PIXEL_VMP_SIGN=1`. При нестандартном Python задайте `PIXEL_VMP_PYTHON`. Хук `scripts/sign-widevine.cjs` подписывает и проверяет распакованный пакет перед созданием EXE. Ошибка подписи прерывает сборку.

Без `PIXEL_VMP_SIGN=1` получается сборка для разработки; наличие SDK и рабочие тестовые кнопки не доказывают, что настоящий Spotify сможет выдавать лицензии. Такой EXE нельзя объявлять проверенной сборкой со встроенным стримингом.

Официальные источники: [Spotify SDK](https://developer.spotify.com/documentation/web-playback-sdk), [Castlabs ECS](https://github.com/castlabs/electron-releases), [бесплатная подпись EVS](https://github.com/castlabs/electron-releases/wiki/EVS).
